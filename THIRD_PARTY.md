- **AetherSDR directory:** factual public metadata snapshots with timestamps in `evidence/live/`. [Documented schema](https://github.com/aethersdr/AetherSDR/blob/main/docs/kiwi-json-schema.md) and [public mirror policy](https://github.com/aethersdr/AetherSDR/blob/main/docs/kiwisdr-public-directory.md). Operator contact email fields in status evidence are redacted because they are not needed for RF validation. Metadata does not constitute captured RF.
- **DCF77 PRN specification:** independent Rust implementation of the mathematical sequence in [PTB-Mitteilungen 114 (2004), section 4.3](https://www.ptb.de/cms/fileadmin/internet/fachabteilungen/abteilung_4/4.4_zeit_und_frequenz/4.42/dcf77.pdf). No third-party decoder is represented as original code.
- **Evaluation coordinates:** [PTB maßstäbe 1, page 23](https://www.ptb.de/cms/fileadmin/internet/publikationen/masstaebe/Hefte_Komplett_PDF/mst01.pdf), used only in the post-hoc evaluator, not the solver.

- **SigMF:** [specification and JSON schema](https://github.com/sigmf/SigMF) (CC BY-SA 4.0). Meridian reads and writes the core fields and defines its own `meridian:` keys.
- **geographiclib-rs** (MIT/Apache-2.0, Rust port of Karney's GeographicLib), **rusqlite** with bundled SQLite (MIT; SQLite is public domain) and **libm** (MIT/Apache-2.0) are Rust dependencies locked in `Cargo.lock`.
- **Native receiver interfaces.** Meridian uses the published KiwiClient SND message format through tokio-tungstenite. Its optional SoapySDR module links the system library. Reference implementation and timing semantics are documented by [KiwiClient](https://github.com/jks-prv/kiwiclient), [SoapySDR](https://github.com/pothosware/SoapySDR) and [UHD](https://github.com/EttusResearch/uhd/blob/master/host/examples/sync_to_gps.cpp).

Rust dependency versions are locked by `Cargo.lock`; JavaScript versions by `package-lock.json`. This project's own code is GPL-3.0-or-later. Upstream assets retain the terms listed above and their original notices.

The NCDXF/IARU International Beacon Project publishes the five frequencies, callsign rotation, Morse timing and six-character locators. Meridian implements its own verifier from these protocol facts. Locators are used only by the post-hoc evaluator.
