# Sources, provenance and licenses

- **DCF77 recordings, receiver coordinates and emission association:** [hcab14/TDoA](https://github.com/hcab14/TDoA/tree/2bb9dc2ecc2c6ebcc13ed11c7cbeadea0cd5dfcd), commit `2bb9dc2ecc2c6ebcc13ed11c7cbeadea0cd5dfcd`, GPL-3.0. Original license: `data/recordings/LICENSE.upstream`. Original WAV bytes and hashes are preserved. Upstream Octave code is not executed; the Rust solver is implemented in this project.
- **KiwiClient:** [official source](https://github.com/jks-prv/kiwiclient/tree/4eb733e6b6147f7fbeb97ced64cdac029b202d18), commit `4eb733e6b6147f7fbeb97ced64cdac029b202d18`. `third_party/kiwiclient-4eb733e6.tar.gz` is an unmodified `git archive`, SHA-256 `c23f94ca325826cb8a0ba5e17f2a974c1318b05726070d5070e8a3b399958cc0`; upstream license files are retained inside it. The README, `src/read_kiwi_iq_wav.cc`, `kiwirecorder.py` and `kiwi/client.py` document capture and timestamps. `scripts/kiwi_transport.py` is a separate standard-proxy adapter with destination and retry restrictions.
- **KiwiSDR `/status`:** [rx_server_ajax.cpp](https://github.com/jks-prv/KiwiSDR/blob/3b570602a14161188f8c85eede62ab2a70e7ad66/rx/rx_server_ajax.cpp), commit `3b570602a14161188f8c85eede62ab2a70e7ad66`. Protocol facts are used; C++ code is not copied into this implementation.
- **Leaflet 1.9.4:** [source](https://github.com/Leaflet/Leaflet), BSD-2-Clause. Distributed locally with its license.
- **Lucide 0.468.0:** [source](https://github.com/lucide-icons/lucide), ISC. License included in `web/vendor/`.
- **Natural Earth 1:110m:** public-domain geographic data, [terms](https://www.naturalearthdata.com/about/terms-of-use/), [source file](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson). The local vector basemap is not RF coverage information.
- **Fonts:** system fonts only; no font files or external font services are bundled.
- **AetherSDR directory:** factual public metadata snapshots with timestamps in `evidence/live/`. [Documented schema](https://github.com/aethersdr/AetherSDR/blob/main/docs/kiwi-json-schema.md) and [public mirror policy](https://github.com/aethersdr/AetherSDR/blob/main/docs/kiwisdr-public-directory.md). Operator contact email fields in status evidence are redacted because they are not needed for RF validation. Metadata does not constitute captured RF.
- **DCF77 PRN specification:** independent Rust implementation of the mathematical sequence in [PTB-Mitteilungen 114 (2004), section 4.3](https://www.ptb.de/cms/fileadmin/internet/fachabteilungen/abteilung_4/4.4_zeit_und_frequenz/4.42/dcf77.pdf). No third-party decoder is represented as original code.
- **Evaluation coordinates:** [PTB maßstäbe 1, page 23](https://www.ptb.de/cms/fileadmin/internet/publikationen/masstaebe/Hefte_Komplett_PDF/mst01.pdf), used only in the post-hoc evaluator, not the solver.

Rust dependency versions are locked by `Cargo.lock`; JavaScript versions by `package-lock.json`. This project's own code is GPL-3.0-or-later. Upstream assets retain the terms listed above and their original notices.
